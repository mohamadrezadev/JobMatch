# KarMatch visual identity

User-approved usage, 2026-10-06. Public name: **KarMatch / کارمچ**. Tagline: **مهارت‌های تو، فرصت مناسب تو.**

| Supplied artwork | Product placement |
| --- | --- |
| Horizontal logo with tagline, `10_06_03 AM-1.png` | Landing hero and product introduction |
| Vertical logo with tagline, `10_06_05 AM-3.png` | Login and registration |
| Horizontal logo without tagline, `10_06_04 AM-2.png` | Desktop header and sidebar |
| K app icon, `10_06_07 AM-4.png` | Mobile header, favicon, Apple touch icon and web manifest icons |

Use the supplied artwork without redrawing/recoloring it. Export only by removing empty margins and resizing proportionally. Wordmarks include dark navy text; use a light backing in dark mode so the name/tagline remain readable. Mobile navigation uses the K mark only. Images require accessible names; the complete logo's alt text includes the tagline.

The web manifest supplies application identity and icons; this change does not add offline caching or promise install prompts. Repository/package/database identifiers remain JobMatch. Retired Academy content is outside the active navigation.

Source files are supplied local PNGs. `frontend/scripts/prepare-brand-assets.cjs` reproduces optimized assets from their containing directory. `frontend/public/brand/assets.json` records source names and output dimensions.
